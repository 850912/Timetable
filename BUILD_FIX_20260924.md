# Wear build fix — 2026-09-24

## CI failure analyzed

The uploaded CI log fails in `:wear:compileDebugKotlin` for two source issues:

1. `PickerPages.kt` called the Wear Material 3 `ScreenScaffold` `edgeButton` slot without a supported list/scroll information provider. The compiler therefore could not resolve a valid overload and produced follow-on composable/type-inference errors.
2. `DayArrangementScreen.kt` used `remember(excluded)` without importing `androidx.compose.runtime.remember`.

The compile SDK 37.2 / AGP 9.2.1 messages in the log are warnings, not the reported build-stopping error.

## Changes

### `PickerPages.kt`

- Removed the invalid `ScreenScaffold(edgeButton = ...)` overload usage from `WearWheelPickerPage`.
- Kept `ScreenScaffold` only for screen/time-text coordination, without an `edgeButton` slot or fake list state.
- Kept `PickerState` as the actual scrolling state and forwarded whole-screen vertical scroll gestures to it using `Modifier.scrollable(...)`, matching the official Wear Material 3 Picker sample pattern.
- Anchored `EdgeButton` directly to `Alignment.BottomCenter` and `fillMaxWidth()`, appropriate for a non-list screen.
- Reduced picker height slightly and added bottom offset so it does not collide visually with the bottom EdgeButton on smaller round screens.

### `DayArrangementScreen.kt`

- Added the missing `androidx.compose.runtime.remember` import.

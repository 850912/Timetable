# 3.3.2 Wear date selection + batch schedule fix

- Removed the separate Wear "多日期创建课时" entry from the time-slot list.
- Normal time-slot creation now includes an "上课日期" selector. It supports multi-select and automatically switches the new slot to DATE_ONLY. Clearing dates returns to weekday + recurrence mode.
- Saving a time slot now waits for repository persistence before leaving the editor, preventing ViewModel cancellation from racing the database write.
- Batch schedule finite ranges now persist as compact inclusive range overrides for recurring lessons instead of resolving and writing one override per occurrence.
- Batch schedule UI no longer exits immediately after apply; it shows an "已应用" confirmation so the result can be verified.
- Restored forward/back page slide transitions inside the batch schedule tool.
- Mobile finite-range batch scheduling uses the same shared compact range operation.
- Version bumped to 3.3.2.

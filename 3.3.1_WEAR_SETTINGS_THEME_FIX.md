# 3.3.1 Wear unified settings & theme fix

- Fixed Wear batch/unified schedule tool subpage back handling. Back/swipe from date/time/offset pickers now returns to the tool main page first.
- Added an open-ended ("永不结束") end-date mode to Wear batch schedule operations. Long-press the end-date row to enable it.
- Open-ended recurring changes are stored as compact range overrides instead of materialising thousands of per-day overrides.
- Added range-aware restore logic that can split an open-ended override when only a finite interval is restored.
- Fixed SYSTEM_DYNAMIC being visually masked by per-course Vibrant subthemes. Global Wear Material 3 dynamic colors now remain authoritative; course/timetable accent colors remain data-level accents.
- Reduced saturation of the legacy blue/teal/purple/orange/pink shell themes.
- Reworked Graphite into a warmer titanium-neutral palette so it is visibly distinct from the default AMOLED black theme.
- Reworked Aurora into a muted teal/lilac palette for higher text readability.
- Bumped phone/watch version to 3.3.1.

Build note: local Gradle execution is still blocked because Gradle 9.4.1 is not cached and the environment cannot resolve services.gradle.org.

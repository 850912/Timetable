# Timetable 3.4.1 source review — 2026-09-19

## Scope

Reviewed the full delivered tree: 196 Kotlin production sources plus manifests, resources,
Gradle configuration, Room schemas, tests, sync, import/export, Tile, complications, mobile, and
Wear modules. The supplied app-market APK and Xiaomi Watch 5 crash capture were used only as
behavior and compatibility references.

## Fixes in 3.4.1

- Replaced all nested `SwipeDismissableNavHost` instances with a plain internal `NavHost`. The
  app-level Wear host is now the sole owner of swipe-dismiss motion, so a child destination no
  longer makes the outgoing page shift left or leave a ghost edge.
- Removed Activity recreation from language selection. A localized Compose context and
  configuration now update strings and locale-dependent date names immediately. Theme, More,
  appearance, power, import, and export labels were moved out of hard-coded Chinese text.
- Disabled AndroidX Wear's new rotary haptic path on all 39 `TransformingLazyColumn` instances and
  the custom date picker while preserving crown scrolling. This avoids loading
  `com.google.wear.input.WearHapticFeedbackConstants` on Xiaomi/HyperOS images that do not provide
  it. App-controlled feedback continues to use stable platform `HapticFeedbackConstants`.
- Added independent **Blur image** and **Fluid image motion** preferences for custom timetable
  backgrounds. Blur is one full-screen pass; fluid motion is a slow GPU layer transform. Both are
  disabled by effective power-saver mode.
- Stopped manually recycling a Compose-visible background bitmap, removing a possible
  `Canvas: trying to use a recycled bitmap` race during background changes.
- Localized theme names and shortened watch summaries. Shared capsule subtitles allow three lines
  where a short summary still needs extra room on round displays.
- Updated About, Developer Options descriptions, dependency summaries, changelog, and version to
  3.4.1. Mobile, Wear, and backup metadata use the same release version and code `3040100`.
- Removed every source reference to the supplied app-market brand.

## Build limitation

The Gradle wrapper requires Gradle 9.4.1 from `services.gradle.org`. Network access to that host is
blocked in this workspace and no matching distribution is cached, so a compiler/device pass could
not be completed here. Run `./gradlew :shared:test :wear:assembleDebug :mobile:assembleDebug` in CI,
then smoke-test launch, language switching, nested settings navigation, and crown scrolling on a
Xiaomi Watch 5 before signing a release.
